# Parcel collection and return

Kora Dispatch holds a parcel at a collection point for seven calendar days after sending the first collection notice. The seven-day period starts on the notice date, not the original dispatch date.

The recipient must present the collection code and a matching identity document. A support agent can explain the policy but cannot waive identity checks.

If the parcel remains uncollected after seven calendar days, a supervisor reviews the case before return to the sender. Relay must not promise automatic extensions or invent storage charges. This policy does not set compensation amounts.
