# Internal collection escalation

Supervisor review code COLLECTION-REVIEW-7 is used for an exceptional collection hold. Only supervisors may read this policy. Support agents must escalate exceptions without quoting internal review codes.

A supervisor must record the reason, the approved collection deadline and the case reference before agreeing to an exception. This policy never overrides recipient identity checks.
